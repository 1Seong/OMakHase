## 게임 소개

오,막하세!는 재료와 조리법을 조합해 새로운 레시피를 발견하는 포인트 앤 클릭 식당 경영 게임입니다.

플레이어는 손님의 요구에 맞춰 요리를 만들고, 재료와 레시피를 해금하며 레시피북을 채워 나갑니다. 다양한 조합과 대사, 멀티엔딩을 통해 반복 플레이에 변화를 줍니다.
